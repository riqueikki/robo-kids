# Monte seu Robô — Robô Maker 🤖

Atividade interativa de **encaixe e coloração de peças** para Educação Infantil e 1º ano do Ensino Fundamental, desenvolvida como recurso de mediação pedagógica para o canal/marca **Robô Maker — Robótica Educacional**.

## O que a atividade trabalha
- Coordenação motora fina (clicar/tocar e arrastar)
- Reconhecimento de formas e correspondência peça-lugar (cabeça, peitoral, braços, pernas)
- Exploração e nomeação de cores
- Registro final da produção (a criança pode salvar/imprimir seu robô, como um portfólio)

## Peças disponíveis
- **5 cabeças**, **5 peitorais**, **4 pares de braços**, **4 pares de pernas** — tudo em SVG, leve e sem necessidade de imagens externas.
- **10 cores** disponíveis para pintar cada peça já encaixada.

## Como a criança usa
1. Escolhe a categoria de peça na "Caixa de Peças" (Cabeça, Peitoral, Braços, Pernas).
2. Toca e arrasta a peça até o contorno tracejado correspondente no robô.
3. Toca na peça já montada para abrir a paleta de cores e pintá-la.
4. Ao final, toca em **"Salvar / Imprimir"** e escolhe: baixar em PNG, baixar em JPG, ou Imprimir/Salvar em PDF (usa a caixa de impressão do navegador — funciona offline).
5. Pode escrever o nome no campo "Nome" para personalizar a folha impressa.

## Publicando no GitHub Pages
1. Crie um repositório novo (ex.: `monte-seu-robo`) e envie o arquivo `index.html` para a raiz.
2. Em **Settings → Pages**, selecione a branch `main` e a pasta `/root`.
3. O link gerado (algo como `https://riqueikki.github.io/monte-seu-robo/`) já pode ser usado em sala, em tablets ou lousa digital — não precisa de internet depois de carregado, nem de instalação.

## Observações técnicas
- Arquivo único (`index.html`), sem dependências externas além das fontes do Google Fonts (carregadas via CDN) — se usar sem internet, as fontes trocam automaticamente para uma fonte padrão do sistema, sem quebrar o funcionamento.
- Funciona em computador (mouse), tablet e celular (toque), graças ao uso de Pointer Events.
- Todo o desenho é feito em SVG (vetor), então a imagem exportada fica nítida mesmo impressa.
